Project Overview
- This project focuses on performing detailed data analysis using a dataset obtained from Kaggle. The goal is to extract meaningful insights, identify trends, and visualize key patterns that can aid in decision-making or understanding the dataset better. To perform this project I have taken reference from other projects.

Dataset Information
Dataset: https://www.kaggle.com/datasets/aslanahmedov/walmart-sales-forecast

Features: Date, Markdowns, Holidays, FuelPrice, Temperature, CPI.

Objectives:
- Clean and preprocess the dataset to handle missing values and inconsistencies.
- Perform exploratory data analysis (EDA) to identify patterns and trends.
- Generate visualizations to effectively present key insights.
